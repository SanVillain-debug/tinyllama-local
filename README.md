# TinyLlama Local

Compañera de chat local con personalidad, memoria, curiosidad autónoma y avatar animado.

Made with [CodeAgent Remix](https://www.codeagent-mobile.com/remix). Live app: https://tinyllama-local-4q7s5wae.remixapps.app/

## Run it locally

A React Native app for [Expo](https://expo.dev) (SDK 54), in TypeScript. You need Node.js 20 or newer.

```bash
npm install
npx expo start   # scan the QR code with Expo Go
```
